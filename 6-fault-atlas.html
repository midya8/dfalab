Exact optimization, explicitly finite scope.

The candidates are all complete declared-m-state machines: unary m ≤ 3 or binary m ≤ 2. Smaller reachable machines occur through unreachable padding. Equivalent candidates are not faults. State labelings and unused states create duplicates, so machine counts are not counts of unique languages or real-world bug frequencies.

Only subsets of the constructed W-suite are optimized: first test count, then input letters, with no shared-prefix credit. Reset before every word. This is not a globally shortest test suite, a production benchmark or a new algorithm.
